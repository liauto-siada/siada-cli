AI 的价值不是取代，

从当前阅读、浏览历史与动作理解意图，

从你的意图开始 ↓ 了解浏览器协作 ↗
UNDERSTAND YOUR INTENT

用户意图感知

刚刚阅读的内容、积累的浏览历史和眼前的操作，都能成为下一步的上下文。

CASE 01

感知 Human 的历史行为

找回你浏览过的论文、GitHub 项目与文章，对照 survey 文章的五条关键结论，把相关工作的解释与对比放回原文对应位置。

input“检索我的浏览历史，找出近期看过的 Browser Agent 相关论文、GitHub 项目与文章，逐条对照 survey 文章的五条关键结论，并在原文对应位置解释与比较。”
CASE 02

感知用户的即时动作

问一句刚才做了什么，Siada 读取动作记录，把点击、滚动与页面跳转整理进回复。浏览与搜索也能按时间列出，串成可读的浏览路径。

input“可以看见我刚才的动作轨迹吗”
MAKE ROOM TO CREATE

利于创造的环境营造

让理解留在现场，让信息继续生长成作品。

把阅读变成作品。围绕页面里的信息，继续生成网页、演示稿或小工具；内容、交互与表达，都从你的意图出发。

CASE 03

就地对当前网页进行渲染

读到哪里，就在哪里解释。翻译、批注与对照直接出现在对应段落旁，让原文和你的思考保持在同一个页面。

“就在这一段下面，解释反思为什么会影响 Agent 的鲁棒性。”
CASE 05

经济财报分析，形成飞书报告

从当前财报页出发，读取多个季度与年度报告，对照收入、毛利率和现金流，把分析、图表与原始来源整理成一份易读的飞书文档。

input“分析该公司的季度业绩和财务报告，形成专业易懂的飞书文档。”
CASE 06

电商信息分析，整理成 PPT

从淘宝商品页出发，搜索百寸电视并收集图片与参数，把机型排行、价格和亮度对比、按需求整理的选购建议，做成 10 页飞书演示稿。

input“搜索100寸电视机性价比排行榜，通过ppt的形式展示。”
BROWSE EFFICIENTLY

高效的浏览器操作

从搜索、页面定位到信息提取，连续完成浏览器操作，并用动作记录回看过程。

CASE 07

浏览器控制与 Trace

通过 Google 找到 GitHub 项目，打开原始配置，整理 Agent 相关依赖、版本与来源。完成后在演示示例中回看 Trace 记录的 25 次动作，查看页面快照、每步工具执行耗时与调用间隔。

input“通过 Google 搜索 Siada CLI GitHub 中 pyproject.toml 中 Agent 相关的依赖。”
