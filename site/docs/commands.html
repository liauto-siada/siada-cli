02 / REFERENCE

命令与快捷输入

输入 / 查找会话命令，用 @ 引用文件，用 ! 运行本地命令。启动参数则在终端运行 siada-cli 时传入。

交互会话里的命令

斜杠命令由当前会话处理。输入命令名前缀时，界面会给出补全；输入 /help 可查看当前版本的完整命令列表。

命令用途
/help查看命令和用法。
/status查看当前模型、Agent、会话 ID 与工作区。
/model打开模型选择器；也可用 /model 名称 指定模型。
/effort [级别]查看或设置当前模型的推理强度，保存到个人配置。
/thinking [on|off]查看、开启或关闭推理；off 优先于推理强度设置。
/theme [auto|dark|light]查看或切换终端主题。
/lang zh-CN / /lang en设置回复语言。
/resume浏览并恢复已有会话。
/clear开启新会话，清空当前对话上下文。
/compact手动压缩当前会话的对话历史。
/btw 问题临时提问，回答不写入主对话历史。
/editor选择外部编辑器编写长提示词。
/export [文件名]在终端 UI 中将当前会话导出为 .txt 文件。
/share生成可在浏览器访问的会话链接，见 会话分享。
/statusbar调整终端 UI 状态栏中各项信息的显示。
/configure重新配置 API Key 或切换登录方式。
/logout退出登录并清除已保存的凭据。
/exit退出交互界面。

目标、记忆与项目规则

命令用途
/goal 目标立即开始推进目标，每轮结束由验证器检查是否完成。
/goal clear移除当前目标。
/task-list查看后台发现的待执行任务。
/memory [enable|disable]查看或调整记忆总开关，保存到个人配置。
/web [enable|disable]查看或调整联网搜索和网页读取工具。
/init分析项目并生成 SIADA.md。
/context-file-refresh刷新 SIADA.md、AGENTS.md 等项目说明。
/rule-init创建空的 siada_rule.md 规则文件。
/rule-list / /rule-show列出已加载的规则文件，或查看合并内容。
/rule-refresh / /rule-status刷新规则，或查看规则加载状态。
/rule-global-add 内容向全局规则文件添加一条约定。
/compare / /undo / /restore比较或恢复检查点，见 文件检查点。

技能、插件与外部工具

命令用途
/skill-list查看当前可用技能；可通过 /技能名 直接调用。
/skill-reload清除缓存并重新发现技能。
/plugin发现、安装、禁用或移除插件，浏览市场并校验配置。
/mcp-server查看 MCP 服务器与连接状态。
/mcp-list查看各 MCP 服务器提供的工具。
/lark-auth / /lark-status为飞书 MCP 工具授权，或查看授权状态。
/lark-refresh刷新飞书 MCP 访问令牌。
/migrate-detect检测 Claude Code、Codex 中可迁移的配置、技能与项目上下文。
/migrate-import导入检测到的配置。

想创建自己的斜杠命令，见 自定义命令。飞书聊天入口支持的命令范围见 飞书中的命令。

启动时传入参数

参数用途
--prompt / -p以非交互模式执行一条提示词后退出。
--model为这次运行指定模型。
--provider default使用自备模型服务，连接信息见 个人配置。
--list-models列出可用模型。
--resume交互模式打开会话浏览器；加会话 ID 可直接恢复。
--reasoning-effort为这次运行指定模型支持的推理级别。
--thinking / --no-thinking开启或关闭模型推理。
--parallel-tool-calls开启并行工具调用；用 --no-parallel-tool-calls 关闭。
--env-file / --set-env加载环境文件，或设置本次进程的环境变量。
--checkpointing在交互模式开启检查点；用 --no-checkpointing 关闭。
siada-browser setup / siada-browser status安装浏览器协作组件，或检查连接。
--daemon-status / --stop-daemon检查或停止后台进程。
--acp作为标准 ACP stdio 服务，由兼容客户端启动。
--version / --help查看版本号或完整启动参数。
TERMINAL
siada-cli --list-models
siada-cli --prompt "总结这个目录中的测试结构"

--prompt 不处理 /model、/resume 等内置会话命令，请改用对应启动参数。非交互模式可在任务文本中明确指定技能，例如 siada-cli -p "使用 review-checklist 检查这次改动"。

文件引用与本地命令

在普通输入中使用 @路径 引用项目文件或目录。需要亲自执行一条本地命令时，以半角 ! 开头输入；空输入框按 ! 也可以切到 Shell 输入模式。

交互输入示例
@src/main.py 解释程序入口
!git status
本地 Shell 会执行输入的命令

!git status 在当前工作目录执行。Shell 输入模式可按 Esc 退出；当前版本没有启用 /shell 命令，请使用 ! 入口。

输入与快捷键

快捷键用途
Enter发送消息。
Ctrl+J插入换行，适合各种终端。
Shift+Enter / Alt+Enter终端支持相应按键协议时插入换行；也支持 Ctrl+Enter。
Esc中断当前回答，关闭补全，或退出 Shell 输入模式。
Ctrl+C中断当前回答；连续按两次退出 Siada。
Ctrl+O切换紧凑与展开的输出显示。
Ctrl+A / Ctrl+E移动到行首或行尾。
Ctrl+W删除光标左侧的一个词。
Ctrl+U / Ctrl+K删除光标左侧到行首，或右侧到行尾。
Alt+← / Alt+→按词左右移动光标。
Ctrl+X在选定的外部编辑器中编辑输入。
Ctrl+B复制输入框内容到剪贴板。
Ctrl+D清空当前输入。
Ctrl+V从系统剪贴板粘贴图片或文字。
