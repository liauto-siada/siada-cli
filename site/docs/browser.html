浏览器协作

在你正在使用的 Chrome 里，把阅读、点击和选择变成任务上下文。Siada 从当前页面理解意图，就地解释内容、整理资料，与你交接操作。

连接你的 Chrome

准备好 Chrome 和已完成模型配置的 Siada，然后安装浏览器协作组件并启动本机代理。

TERMINAL
siada-browser setup
siada-browser status
平台组件包尚未发布

匹配当前平台的组件包尚未发布，现在还无法远程安装。请先按 浏览器安装与发布 指南从源码构建并安装；组件包发布后，运行 siada-browser setup 即可从 GitHub Releases 下载并安装。

  1. 按安装输出打开 chrome://extensions，启用开发者模式，加载输出指定目录中的扩展。
  2. 按安装提示设置代理地址与连接 token。使用安装输出中的值。
  3. 点击 Chrome 工具栏中的 Siada 图标，打开侧边栏并连接，然后选择或新建会话。

首次使用前，在终端启动一次 siada-cli 并完成登录或 API Key 设置。侧边栏会使用本机的模型配置。

先检查浏览器连接

如果已经配置好浏览器扩展，运行 siada-browser status 查看本机代理状态。输出中的 running 表示代理是否运行；代理运行时，extensionConnected 表示扩展是否连上代理。

TERMINAL
siada-browser status
siada-browser start
siada-browser restart

用 siada-browser start 启动已有安装，siada-browser stop 停止，siada-browser restart 重启。代理正常而扩展未连接时，检查 Chrome 中的扩展加载状态和连接设置。

把眼前的信息继续变成作品

可以直接说清当前页面、要参考的资料与结果放在哪里。几种适合从当前浏览继续的任务：

场景对话示例
就地阅读“翻译当前段落，保留原文，在下面解释图中的几个概念。”
历史资料对照“找出我近期浏览过的相关论文和项目，对照这篇 survey 的结论，在对应段落解释。”
整理与分享“整理刚刚看过的文章，分类并保留原文链接。”需要发布时再指定平台与接收方。
从网页创作“根据这篇网页的要点，做成一个可演示的网页，并保留来源。”

连接相应工具并具备访问权限后，可继续把结果写入飞书文档或消息。示例视频见 阅读整理与分享 和 历史资料对照。

告诉 Agent 要操作什么、怎样算完成

描述目标页面、筛选条件、要交付的文件和核验方式。需要你在页面上示范或修正时，可以在同一标签页操作，然后继续让 Agent 完成后续步骤。

侧边栏输入示例
在当前网站搜索“发布说明”，遍历全部结果页。
导出标题、日期和链接到 results.csv；
最后用页面显示的总条数核对文件行数。

导出完成后，要求回读文件并核对列名、行数和来源链接；操作网页时，检查最终页面是否符合条件。

在同一页面交接操作

你可以在同一标签页里修改筛选条件、选择一段文字或示范一步，然后说“按我刚刚的选择继续”。Siada 重新观察当前页面，再推进后续步骤。

把结果作为完成依据

明确的验收条件有助于区分成功、失败与尚未验证的结果。导出文件应回读核对，网页操作也应检查目标页面的最终状态。

通过浏览器分享会话

用 /share 生成当前会话的网页链接。接收方可以在浏览器里查看并参与这段对话；本机代理需要对接收方可达。

TERMINAL · 允许局域网设备连接
siada-browser setup --host 0.0.0.0
Siada 会话输入
/share

链接会自动复制到剪贴板。接收方打开链接后可载入会话；自签名证书环境首次访问时，按提示确认你自己的代理地址。

链接也包含操作权限

分享链接中的 token 授予完整 Agent 控制权，请只交给可信任的人。仅绑定本机 127.0.0.1 时，/share 会提示不能远程分享。

让可验证的经验用于下次任务

完成一套稳定流程后，可以要求 Siada：“把刚才的步骤整理成 Skill，写清适用网站、前提和每一步的检查方法。”下次指定技能名称，就可以从已有方法开始。

页面改版时仍需重新核对元素和结果。Skill 的目录与调用方式见 技能管理。
