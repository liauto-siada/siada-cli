模型与配置

可以在会话里切换模型，为某一次运行指定参数，或把个人偏好写到 ~/.siada-cli/conf.yaml。实际可用的模型取决于你配置的服务。

在会话中选择模型

输入 /model 打开模型选择器。要直接选择一个已配置的模型，可以输入 /model 模型名称；在终端运行 siada-cli --list-models 也可查看当前可用模型。

交互输入
/model
/status

选择后用 /status 确认当前模型。/model 的选择会保存到个人配置中；仅想临时指定模型时，使用启动参数更合适。

只影响这次运行

启动参数优先于个人配置。使用 --model 指定模型，--reasoning-effort 设置推理强度，或 --no-thinking 关闭推理；具体值需与模型支持的能力匹配。

TERMINAL · 将 MODEL_ID 换成可用模型
siada-cli --model MODEL_ID --reasoning-effort high
siada-cli --model MODEL_ID --no-thinking

配置自己的模型服务

在会话中输入 /configure，按提示选择服务并填写 API Key。也可以编辑 ~/.siada-cli/conf.yaml，在 llm_config 中设置模型、服务地址与密钥。使用自备 API 服务时，Siada 的 provider 设为 default。

~/.siada-cli/conf.yaml · 示例
llm_config:
  provider: default
  model: "your-model-id"
  base_url: "https://api.example.com/v1"
  api_key: "YOUR_API_KEY"
替换示例值

模型 ID、地址和密钥请使用服务商提供的实际值。密钥保存在个人配置或环境变量中，避免提交到项目版本库。

推理和界面偏好

这些偏好可以直接在会话里设置并保存到 conf.yaml，通常无需手动编辑配置。

操作配置项与含义
/effort highllm_config.reasoning_effort：推理强度；不同模型的级别不同，输入 /effort 查看。
/thinking on / offllm_config.enable_thinking：推理总开关；关闭后优先于推理强度与 token 预算。
/theme autoui.theme：跟随系统或终端；也可设为 dark、light。
/lang zh-CNpreferred_language：回复语言；英文使用 en。

图片与视觉模型

主模型支持图片时，截图可以直接参与任务。如果主模型无法读取图片，可设置 llm_config.vision_model，让视觉模型先提取文字证据，再交给主模型处理。

conf.yaml · 为 llm_config 补充
llm_config:
  model: "your-main-model"
  vision_model: "your-vision-model"
  vision_provider: default

这里仅展示视觉相关字段，添加到已有 llm_config 中即可。视觉模型必须是你已配置、可访问且支持图片的模型。

常用运行设置

没有对应命令的设置，可直接编辑 conf.yaml，或使用 /siada-help 请 Siada 帮你调整并检查类型。

配置项用途
code_agent.max_turns一次 Agent 执行的最大轮数，使用整数。
command_timeoutShell 命令超时秒数，使用整数。
goal.max_turns目标验证连续失败时允许自动续跑的轮数，默认 6。
checkpoint_config.enable交互模式的文件检查点开关，见 检查点。
memory.enabled记忆总开关；可用 user_profile_enabled、memory_facts_enabled 控制记忆内容。
memory.holographic.enabled结构化事实记忆开关，受 memory.enabled 总开关控制。
web.enabled联网工具开关：true 开启，false 关闭。
sub_agent.enabled子 Agent 派发开关；关闭后任务由主 Agent 完成。
sub_agent.llm_config为子 Agent 配置模型；未设置时沿用父会话模型。
proactive.llm_config后台与定时任务的专用模型，见 后台设置。
compaction_strategy上下文压缩策略；省略时自动选择，支持 header_summary、turn_prune_summary。
enable_notification任务结束后的系统通知开关。

各类配置放在哪里

文件内容
~/.siada-cli/conf.yaml模型、界面、记忆、子 Agent 和后台等主要偏好。
~/.siada-cli/models.json单个模型的上下文窗口、价格与推理等覆盖设置。
~/.siada-cli/mcp_config.jsonMCP 服务器；项目可用 siada_mcp_config.json。
~/.siada-cli/commands/自定义命令的 TOML 文件。
~/.siada-cli/workspace/cron_tasks.json由定时任务技能维护的周期任务。

让手动配置生效

手动修改 conf.yaml 后，重启后台并重新启动会话，使各组件重新读取配置。随后用 /status 核对当前模型与工作区。

TERMINAL
siada-cli --stop-daemon
siada-cli

如果不确定配置是否有效，输入 /siada-help 帮我检查 conf.yaml 的语法与配置项。模型连接问题见 常见问题。
