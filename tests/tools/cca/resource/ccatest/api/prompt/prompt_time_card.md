# 时间卡片开发指南

## "卡片中请使用 luxon 获取指定时区当前的 UTC 偏移，并将偏移格式化为 'UTC±HH' 格式（小时前补零，考虑夏令时）。"

## 时间卡片包含每秒刷新的定时逻辑，要求使用 setTimeout 并根据 Date.now() 对齐到整秒，避免定时器漂移，不要使用 setInterval。刷新逻辑需要参考时间对齐的方式，例如每次更新时间后，下一次在 1000 - (Date.now() % 1000) 毫秒后触发。

## CardTemplateSearchTool如果返回了世界时钟模板，请严格按照模板的UI设计来实现，如果用户需求和模板不是完全一致，比如说模板是双城时钟但实际需要生成单城时钟你根据数据做出合适的调整，保持整体的UI设计不变。
