# 离线会话回归测试

在当前检出目录的 Poetry 环境中运行会话与上下文回归测试：

```bash
export REPO_ROOT="$(git rev-parse --show-toplevel)"
poetry -C "$REPO_ROOT" run python "$REPO_ROOT/tests/run_session_baseline.py"
```

使用 `--scope new` 仅运行存储和请求边界测试，使用 `--list` 查看所选路径。
运行器使用临时用户环境和内存中的模型响应；任何意外网络连接都会使运行失败。

测试覆盖版本化存储、旧会话迁移、恢复、检查点、排队输入、提醒、上下文压缩，
以及流式和非流式模型请求的持久化边界。启用有效上下文桥接时，hook 新增内容
在调用模型前持久化，仅清理已提交的队列；旧调用路径保留响应结束时的提醒持久化。

三个严格预期失败记录旧路径的行为缺口：请求失败后通知丢失、空旧快照回退到
历史记录，以及仅含摘要的旧会话恢复原始历史。新格式有效上下文的对应行为由
独立测试覆盖。预期失败表示尚存缺口，不代表这些旧路径已经验证通过。
