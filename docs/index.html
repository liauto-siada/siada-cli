Siada 使用手册

从一句清楚的意图开始，一起写代码、理解网页、整理信息和创造作品。在这里找到你的第一步，也找到下一次协作需要的命令与配置。

安装与 API Key 配置

当前正式版本为 1.7.35。先安装 Siada，再配置服务地址、模型和 API Key，即可开始第一段对话。

1.7.35安装与版本验证 API Key配置自己的模型服务 Chrome浏览器安装与连接

从一段对话开始

在项目目录启动 Siada，告诉它目标、范围和怎样算完成。你可以继续追问、补充材料，或在浏览器里示范一步，让它接着完成后续工作。

按你的下一步查找

先上手，再按需要调整模型、接入工具，或把重复工作交给后台。每章都给出可以直接使用的入口。

01 / START 开始使用 第一次对话、脚本调用与文件引用。 02 / REFERENCE 命令与快捷输入 常用斜杠命令、启动参数和终端输入方式。 03 / CONFIG 模型与配置 切换模型、指定单次参数与维护个人配置。 04 / CONTEXT 会话、上下文与记忆 恢复对话、检查点、目标模式与跨会话记忆。 05 / EXTEND Skills、Agent 与插件 项目规则、自定义命令、MCP 与 Hooks。 06 / BROWSER 浏览器协作 连接 Chrome、就地阅读与创作、交接和分享会话。 07 / AUTOMATION 后台与定时任务 守护进程、周期任务、每日摘要与自动更新。 08 / CONNECT 飞书与 ACP 接入 从飞书远程协作，或在支持 ACP 的编辑器中使用。 09 / HELP 常见问题 启动、配置、浏览器连接与会话恢复的排查入口。

记住几个常用入口

/model切换模型 /resume接着上次的工作 /goal持续推进目标 /skill-list查看可用技能

在对话中输入 /siada-help，也可以直接问“如何设置定时任务”或“帮我检查配置”。它会按你的问题解释用法，或帮助调整配置。
