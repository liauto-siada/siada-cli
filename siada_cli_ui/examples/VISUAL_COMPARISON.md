## 颜色渐变示意图

```
左侧 (起始)                                                   右侧 (结束)
    │                                                              │
    ▼                                                              ▼
#5b8cd5 ──→ #6BA5E7 ──→ #79B8FF ──→ #7FC9E8 ──→ #85D89D ──→ #85E89D
  蓝色        亮蓝色      浅蓝色       青色       浅青绿       浅绿色
```

**渐变算法：**
```
字符位置 → 计算比例 → 映射颜色索引 → 应用颜色
    0%           0          Color[0]      #5b8cd5 (蓝)
   20%         0-1         Color[0-1]    #5b8cd5 → #6BA5E7
   40%         1-2         Color[1-2]    #6BA5E7 → #79B8FF
   60%         2-3         Color[2-3]    #79B8FF → #7FC9E8
   80%         3-4         Color[3-4]    #7FC9E8 → #85D89D
  100%           5          Color[5]      #85E89D (绿)
```

## 性能对比

### 渲染次数测试

**场景：** 父组件每 2 秒更新一次，共更新 10 次

#### 不使用 Static 组件
```
渲染次数：
├─ 初始渲染: 1 次
├─ 更新 1-10: 10 次
└─ 总计: 11 次完整渲染

每次渲染内容：
└─ 横幅 (6 行 × 67 字符 = 402 个 Text 组件)
└─ 动态内容
```

#### 使用 Static 组件
```
渲染次数：
├─ 横幅: 1 次 (Static)
├─ 动态内容: 11 次 (初始 + 10 次更新)
└─ 总计: 横幅 1 次，内容 11 次

性能提升：
└─ 横幅渲染减少: 90.9% (从 11 次降到 1 次)
```

**结论：** 使用 Static 组件可以显著减少不必要的渲染，节省 CPU 和内存资源。

## 自定义建议

### 修改颜色方案

**暖色调（红橙黄）：**
```javascript
const warmColors = [
  '#FF6B6B', // 红色
  '#FF8E53', // 橙红
  '#FFB347', // 橙色
  '#FFDB58', // 金黄
  '#F7DC6F', // 浅黄
  '#F9E79F', // 淡黄
];
```

**冷色调（蓝紫）：**
```javascript
const coolColors = [
  '#667EEA', // 深蓝紫
  '#764BA2', // 紫色
  '#9B59B6', // 淡紫
  '#BB8FCE', // 浅紫
  '#D2B4DE', // 很淡紫
  '#E8DAEF', // 极淡紫
];
```

**单色调（灰度）：**
```javascript
const grayColors = [
  '#212121', // 深灰
  '#424242', // 中深灰
  '#616161', // 中灰
  '#757575', // 中浅灰
  '#9E9E9E', // 浅灰
  '#BDBDBD', // 很浅灰
];
```

### 修改 ASCII 艺术

你可以使用在线工具生成自定义的 ASCII 艺术：
- [Text to ASCII Art Generator](http://patorjk.com/software/taag/)
- [ASCII Art Generator](https://www.asciiart.eu/text-to-ascii-art)

然后替换 `bannerLines` 数组中的内容。
